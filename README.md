# TinPTNK-Editor
Edit code inside TinPTNK OJ (and some other PTNKOJ) and submit through text with auto file detection. Increase your productivity!

|                       OJs                       	| Status 	|
|:-----------------------------------------------:	|:------:	|
|        [TinPTNK](http://www.tinptnk.com/)       	|    ✅   	|
| [haitptt](http://haitppt.ddns.net:81/index.php) 	|    ✅   	|

# Ace Editor version
Integrated Ace Editor inside OJ
You can also use:
- `ctrl+S` for auto pasting and submit with clipboard
- `alt+S` auto turn on file selecting menu and submit the file you chose

<img width="1341" height="1030" alt="image" src="https://github.com/user-attachments/assets/4b26c44b-b149-4821-88dd-c468f1fc1fa4" />

## 📖 How to download
> Requirements for download: Use must have [Tampermonkey](https://www.tampermonkey.net/) or similiar tools installed on your browser

There are 3 ways:
1. Go to [source file](TinPTNK-Submitter-Ace-Editor.user.js) and view in source in raw mode. A Tampermonkey installation query will appear.
2. Download from [Greasy Fork](https://greasyfork.org/en/scripts/588506-tinptnk-submitter)
3. Copy [source file](TinPTNK-Submitter-Ace-Editor.user.js) and paste it inside your Tampermonkey
